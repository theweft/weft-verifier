# Security policy

weft-verifier is security-critical code. Please report vulnerabilities **privately**:

- GitHub: "Report a vulnerability" on the repository's Security tab (private advisory), or
- email: security@theweft.org

Please include a description, affected versions and, if possible, a reproducing input.
We acknowledge reports within 3 working days and coordinate disclosure with you.

Only the latest release receives security fixes until a long-term support policy is published.
